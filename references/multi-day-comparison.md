# 多日对比分析模式

当用户要求对比多天数据时（如"前两天和今天的健康"），使用以下模式：

## 数据获取

对每个日期分别调用 health_snapshot.py：

```bash
python3 {skill_dir}/scripts/health_snapshot.py --date 2026-05-17 > /tmp/day1.json
python3 {skill_dir}/scripts/health_snapshot.py --date 2026-05-19 > /tmp/day2.json
```

## 分析框架

### 1. 并排对比表

| 指标 | 日期A | 日期B | 变化 |
|------|-------|-------|------|
| 步数 | 3176 | 657 | ↓ 79% |
| HRV | 52ms | 40ms | ↓ 23% |

变化用百分比和箭头标注，直观显示趋势方向。

### 2. 状态判断

- HRV 下降 + RHR 上升 = 疲劳信号
- HRV 上升 + RHR 下降 = 恢复良好
- 压力上升 + 身体电量下降 = 累积疲劳
- 深睡连续偏低（<15%）= 睡眠质量根因

### 3. 根因分析

不只是报数字，要分析"为什么"：
- 深睡不足 → 身体修复不够 → 疲劳累积
- 压力升高 → 交感神经活跃 → HRV 下降
- 步数减少 → 活动量不足 → 身体电量恢复慢

### 4. 时间跨度

- 2天对比：看急性变化，判断是否需要 immediate intervention
- 7天趋势：看慢性变化，判断是否需要调整生活方式
- 结合两者：急性变化叠加慢性趋势 = 高优先级
